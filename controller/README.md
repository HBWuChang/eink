# HUAWEI A0 墨水屏控制器

Flutter macOS / Android 应用：选择图片、旋转、裁剪、四色量化，通过 BLE 发送到 ESP32-S3 并刷新 A0 墨水屏。

## 运行

```bash
flutter pub get
flutter run -d macos
```

构建：

```bash
flutter build macos
```

首次使用会触发 macOS 蓝牙权限。应用已配置蓝牙和用户选择文件的 sandbox 权限。

## Android

```bash
flutter run -d <Android设备ID>
flutter build apk --debug
```

APK 输出：`build/app/outputs/flutter-apk/app-debug.apk`。
首次扫描时允许蓝牙/附近设备权限；Android 11 及以下还需要定位权限和开启系统定位服务。
蓝牙未开启时会弹出系统开启请求。图片通过系统文件选择器选择。

页面使用安全区域的可用宽高：高大于宽时，图片编辑区、蓝牙设备和发送历史从上到下排列，展示区为 1:1，整页可滚动；横屏保留左右分栏，高度不足时可上下滚动。
展示区的正方形比例不改变墨水屏输出的 768 × 552 尺寸与裁剪框比例。

## 技术栈

- GetX 状态管理
- Hive 本地发送历史、上次设备
- flutter_blue_plus BLE
- image 图片解码/旋转/裁剪/量化
- Floyd–Steinberg 四色抖动，与 Android 项目 `ImageRaster` 一致

## BLE 设备

广播名：`HUAWEI-EPD-A0`

完整协议、接线和固件构建见上一级目录的 `README.md`。

## YT 状态（macOS）

首页右上角打开 **YT 状态**，路由 `/yt-status`。可导入 ytstatus 的
`config.json`，或输入并保存配置：`base_url`、`token`、`query`、
`report_id`、`ranking_limit`（1–50）、`expiration_field`、`timezone`。
导入只读取 YT 相关字段，不读取 utui/adb 配置。Token 保存在应用私有 Hive
设置中，非 Keychain 加密；不要分发应用数据目录。

新增 `scan_timeout_seconds` 默认 30 秒（1–300），`warning_hours` 默认 24 小时。
启用后台定时更新后立即检查，此后每 10 分钟检查一次；重启应用后恢复已启用状态。
HTTP 失败保留屏幕当前内容，不当作 0 条；月榜失败独立显示。
到期时间按配置时区显示，无过期时间排最后。

先正常发送一张图片：成功刷新后保存其完整 768×552 / 2bpp 数据，跨重启保留。
YT 更新在这张底图叠加 480×264 像素状态面板，显示总数、过期数、预警数、更新时间。
红色表示存在距到期不超过 2 小时的项目（含已过期），黄色表示存在其余预警期内到期项，其余黑色。
支持 `text_rotation`：0、90、180、270 度；`text_position`：左上、上中、右上、左中、居中、右中、左下、下中、右下（九宫格）。位置按最终屏幕坐标计算，默认 0 度、下中；竖向旋转后面板为 264×480，不会越界。
每次都重新从底图叠加，YT 发送不写入底图和发送历史。底图不存在时仅查询，提示先发送图片。

所有图片发送会自动搜索 `HUAWEI-EPD-A0`、连接、发送、等待固件报告刷新完成，
随后断开连接；失败也会清理连接。发送进行中不会启动第二次发送。

macOS 关闭窗口继续运行，可用菜单栏 **EPD** 重新打开或退出。
启用 YT 时通过 NSProcessInfo activity 防止 App Nap，并显式建立 IOPM 防空闲睡眠断言，允许屏幕关闭及锁屏。
macOS 每十分钟由原生 DispatchSourceTimer 触发更新；初始化握手失败或断言失败会在页面显示。
系统主动睡眠、合盖、关机或退出应用期间不执行任务；唤醒后补一次检查。
这不安装开机启动服务，需要登录后自行启动应用。

YT 状态页提供实时像素预览：使用最后一次正常发送的底图，没有底图时明确显示白底示例。
调整方向、九宫格位置、预警小时数或时区后，无需保存即可预览；正式发送使用保存后的配置。
“保存配置并查询数量（仅预览）”可以只查询、不触发发送；后台定时发送仍按开关状态独立执行。
预览与发送共用同一个文字栅格化和四色 2bpp 叠加函数。状态面板显示中文，
macOS 使用 CoreText、PingFang SC（苹方）和 CPU 位图上下文绘制，不依赖 Flutter 的 GPU 离屏渲染；其他平台使用 TextPainter。

文字背景为透明：先将文字笔画与其下方的底图像素按透明度合成，再量化到四色；
没有笔画覆盖的位置保持底图的原始 2bpp 数据，包括文字区域内部的留白。

“已过期／即将到期”下方显示到期时间升序的前三条 YT（含已过期，无时间排最后），
格式为“X时XX分  YT编号”，显示距离到期的剩余时长（超过一天累计为小时），字号与“YT 剩余”相同（40）。
已过期条目以负号和红色表示逾期时长；未到期的不足一分钟部分向上取整。
每行独立着色：距离到期不超过 2 小时（含已过期）红色、其余预警期内黄色、其余黑色；无时间显示“无到期时间”。
预览与发送同步生效，背景保持透明，文字区域扩展为 480×264 以容纳三行。

### 锁屏更新诊断

YT 状态页显示原生定时器／防睡眠是否已建立，并持久保存最近 60 条任务记录，
页面展开“后台更新记录”可查看最近 15 条。记录包含触发、查询、绘制、蓝牙发送和结束阶段，
不记录 Token、请求头或 Issue 标题。也可运行 `pmset -g assertions`，
查找 controller 进程的 `EPD YT scheduled refresh` 防睡眠断言。

应用未注册 SMAppService 登录项或后台辅助服务，因此不保证出现在系统设置
“登录项与扩展／App 后台活动”列表。该列表不等于普通已运行应用的后台运行权限。
仍需先启动应用并保持进程运行；主动睡眠／合盖／关机期间不执行，唤醒后补查。

状态栏 EPD 入口在原生窗口初始化时创建，并在应用激活、后台通道调用、唤醒时恢复可见性，
不再只依赖 applicationDidFinishLaunching 回调。红色阈值固定为剩余不超过 2 小时，
包括全部已过期任务；“已过期”统计仍只计算真正过期的任务。

### 下班倒计时

YT 状态页可选工作时长 **9 小时／12 小时**（默认 12）。点击“导入 clockOut 配置”，
选择原项目 `ClockViewModel.swift`，自动提取打卡接口 URL 和 `x-access-token`；
保存配置后使用“保存配置并查询数量（仅预览）”查看效果，或等待定时更新。
也可直接填写 `clock_url`、`clock_token`；凭据仅存本地设置，不写入源码。

沿用 clockOut 规则：当日 `clockInTime + work_hours` 为下班时间，末行显示
“还有XhXXm下班”或“可以下班了”。使用配置时区，未满一分钟向上取整。
忽略周末及接口休息日标记，始终按当日打卡时间计算；无打卡显示“下班：尚未打卡”，查询失败独立提示，
不会阻止 YT 发送；跨日不复用昨日倒计时。每次 YT 更新一并查询打卡数据。
新增末行保持透明背景、40 字号，区域扩展到 480×360，四方向和九位置仍适用。

下班倒计时下方另起一行显示 `WK:XX ALL:XX S:XXX`，分别对应打卡接口
`totalStruggleOt`、`striver`、`lateAndEarlyRemaining`，保留接口原值和单位，
缺失／查询失败时显示 `--`，零值正常显示 `0`；该行使用 24 字号，透明背景。
